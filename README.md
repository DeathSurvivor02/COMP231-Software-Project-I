## 📋 Project Overview & Architecture

Clinical AI Suite is an enterprise clinical ambient intelligence platform designed to automate clinical documentation, patient conversational intake, and front-desk appointment operations.

### Technology Stack
- **Backend API:** Node.js / Express REST API with TypeScript / Spring Boot architecture
- **Frontend Client:** React / Vite responsive web app with interactive audio waveform capture
- **Testing Suites:** Node.js native test runner, Jest/Supertest, and Cypress E2E flows
- **CI/CD:** GitHub Actions automated build & test pipeline (`.github/workflows/ci.yml`)
- **Agile Project Management:** GitHub Issues with Fibonacci story points, milestone tracking, and PR review templates

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm (v9.0.0 or higher)
- Git

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DeathSurvivor02/COMP231-Software-Project-I.git
   cd COMP231-Software-Project-I
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run Unit & Integration Tests:**
   ```bash
   npm test
   ```

4. **Start Development Server:**
   ```bash
   npm start
   ```
